# SURGILENCE (PVT) LTD — Precision Surgical & Dental Instruments

Modern, medical-professional friendly web application and digital product showcase for **SURGILENCE (PVT) LTD**, a certified manufacturer and exporter of surgical and dental hand instruments.

## 🩺 Overview & Scope
- **Specialization**: 100% manual forged steel surgical and dental hand instruments.
- **Strict Policy**: Zero electrical/electronic appliances (strictly manual surgical and dental instruments).
- **Standards & Metallurgy**: German & French stainless steel (AISI 420 / AISI 410 / Tungsten Carbide inserts), ISO 13485:2016 certified, CE MDR 2017/745 Class I & IIa compliant, ASTM A967 chemical passivation.

## 🚀 Key Features
- **Interactive Product Catalog**: Instant search, department filtering (Surgical vs. Dental), alloy grade filters (AISI 420 vs. Tungsten Carbide Gold).
- **Technical Specification Modal**: Comprehensive metallurgy, Rockwell hardness rating (HRC), autoclave sterilization limits (134°C / 273°F), tip configurations, and custom laser etching options.
- **B2B Request for Quote (RFQ) System**: Side-drawer quote basket, customized quantities, automated reference code generation (e.g., `RFQ-SL-XXXXXX`), printable quotation sheet, and direct WhatsApp / email dispatch.
- **Company & Compliance Showcases**: ISO 13485 quality protocols, 4-stage testing verification, OEM private labeling, and global logistics.
- **Direct Communication**: One-click WhatsApp contact (`+92 309 1699666`), commercial export email, and integrated social channels.

## 🛠️ Technology Stack
- **Framework**: Vite + React 19
- **Styling**: Modern Vanilla CSS Design System (Clinical Sapphire, Cyan Laser & Surgical Steel with Glassmorphism)
- **Typography**: Google Fonts (Outfit, Inter, JetBrains Mono)
- **Icons**: Custom Medical SVG Icon System

## 📦 Getting Started Locally

```bash
# Install dependencies
npm install

# Run local development server
npm run dev

# Build for production
npm run build
```

## 🖼️ Adding Brand Logo
Drop your custom company logo into:
```
public/images/logo.png
```
The application will automatically detect and render your logo across the navbar, footer, and brand marks.
